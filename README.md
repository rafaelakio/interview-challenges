# 🎯 Interview Challenges - Desafios de Engenharia de Software

Coleção completa dos principais desafios técnicos utilizados em entrevistas de empresas de tecnologia, com documentação detalhada sobre o propósito de cada desafio e múltiplas soluções.

## 📋 Índice

### Backend Challenges
1. [URL Shortener](#url-shortener) - Sistema de encurtamento de URLs (Bitly, TinyURL)
2. [Rate Limiter](#rate-limiter) - Controle de taxa de requisições
3. [Cache System](#cache-system) - Sistema de cache distribuído (Redis-like)
4. [Task Queue](#task-queue) - Fila de processamento assíncrono
5. [API Gateway](#api-gateway) - Gateway de APIs com roteamento
6. [Event Sourcing](#event-sourcing) - Sistema de eventos e auditoria
7. [Distributed Lock](#distributed-lock) - Lock distribuído para sistemas concorrentes
8. [Search Engine](#search-engine) - Motor de busca com indexação

### Frontend Challenges
1. [Infinite Scroll](#infinite-scroll) - Scroll infinito com virtualização
2. [Autocomplete](#autocomplete) - Sistema de autocompletar com debounce
3. [Drag and Drop](#drag-and-drop) - Interface drag-and-drop
4. [Real-time Dashboard](#real-time-dashboard) - Dashboard com dados em tempo real
5. [Form Builder](#form-builder) - Construtor de formulários dinâmicos
6. [State Management](#state-management) - Gerenciamento de estado complexo
7. [Component Library](#component-library) - Biblioteca de componentes reutilizáveis
8. [Virtual DOM](#virtual-dom) - Implementação simplificada de Virtual DOM

### Full Stack Challenges
1. [Chat Application](#chat-application) - Sistema de chat em tempo real
2. [E-commerce Cart](#e-commerce-cart) - Carrinho de compras completo
3. [Authentication System](#authentication-system) - Sistema de autenticação JWT
4. [File Upload System](#file-upload-system) - Upload de arquivos com chunks
5. [Notification System](#notification-system) - Sistema de notificações push

## 🚀 Como Usar

Cada desafio contém:
- **Contexto**: Por que esse desafio é usado em entrevistas
- **Requisitos**: O que deve ser implementado
- **Conceitos Avaliados**: Habilidades técnicas testadas
- **Soluções**: Múltiplas abordagens (básica, intermediária, avançada)
- **Trade-offs**: Análise de prós e contras de cada solução
- **Perguntas Comuns**: O que os entrevistadores costumam perguntar
